# Shared repository workflow

- Source of truth: https://github.com/GarvGupta25/Helm_AI. The owner and a friend share this repository. Use the Helm_AI checkout, never assume Insurance_UAE is the same project.
- Before work: inspect branch/status, fetch origin and pull --ff-only when clean. Preserve uncommitted work. For independent branches use codex/ by default. Never force-push or overwrite shared work.
- Finish a complete change, run appropriate checks, stage only intended files, commit, fetch again, integrate remote changes, and push. The owner authorised phasewise development and pushes without repeated approval pauses. Current development author: Utkarsh Raj <rajutkarsh2408@gmail.com>.
- Never commit credentials, .env files, capabilities, databases, raw logs or dependency folders. Generated tracked egg-info and browser evidence can change during checks; preserve collaborators' changes and restore only artifacts generated by your own run when not intended for the change.

The guided pages now deliberately retain a light palette under dark OS settings, with explicit readable card foregrounds.
