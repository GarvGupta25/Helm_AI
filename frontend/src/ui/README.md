# UK primitives

Import `uk.css` once at the public layout boundary. All classes are prefixed to avoid changing the archived professional workspaces. `primitives.tsx` exports labelled fields, checkboxes, actions, badges, cards, native accordions, Radix dialogs/tooltips/tabs, reduced-motion, skeleton and status components. Dialogs trap focus and restore it to their trigger. Controls have 48px targets and visible focus rings. Use an explicit `type="button"` for non-submit buttons inside forms.

Storybook/Ladle and a complete per-component test catalogue remain outstanding; see phase reports rather than assuming documentation is a substitute for those checks.
